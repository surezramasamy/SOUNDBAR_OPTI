Pioneer DMH-Z5290BT (Standard Mode) FRONT COMPONENT + REAR COAX + SUB

Step 1: Pioneer Standard Mode Pre-Test Setup

  1. Connect your phone to the Pioneer DMH-Z5290BT via Bluetooth or Android Auto / CarPlay.
  2. Go to Settings ⚙️ $\to$ Audio $\to$ Speaker Level and set all 5 channels (Front Left, Front Right, Rear Left, Rear Right, Subwoofer) to 0 dB.
  3. Since your Front is a 2-Way Component (Mid + Tweeter on one channel) and Rear is Coaxial:
    • Keep Fader = 0 (Center) when testing Front Left / Front Right / Subwoofer.
    • Temporarily set Pioneer Fader = Rear when testing Rear Left / Rear Right so only the rear coaxials play, then return Fader to 0.
  4. Hold the phone at ear height at the driver's headrest and tap Test All Car Channels (or test each channel individually).
