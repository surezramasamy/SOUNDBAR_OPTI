Using with Spotify / YouTube Music on Android

Because phone web browsers are sandboxed from modifying Spotify's internal audio stream directly:
  • Option 1 (Native Android Service — Included in Repo): Build the included Kotlin service in android_spotify_passthrough/ which attaches Android's DynamicsProcessing Equalizer to audioSessionId = 0 so Spotify & YouTube Music pass through this exact mic-driven subwoofer ducker in the background.
  • Option 2 (System Wavelet / Dolby Atmos + Live Monitor above): Keep this live monitor running on your dashboard to see the exact live dB cut while Spotify plays.
